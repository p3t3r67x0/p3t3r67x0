## 🗺️ What I'm working on

### Open City Planner

A modular, open-source **web GIS for urban planning, spatial analysis, and open geodata**.

The project combines interactive mapping with tools for working with areas, spatial information, OpenStreetMap data, and reusable GIS modules — directly in the browser.

- 🌍 Live: https://stadtplaner.oklabflensburg.de
- 💻 Source: https://github.com/oklabflensburg/open-city-planner
- 🧩 Focus: modular GIS architecture, spatial analysis, Open Data and reusable civic-tech components
